About The Project

脑波分析、音乐映射与生成评估接口的一体化前端入口

The Brainwave Alpha Project 聚焦 EEG 数据到音乐生成之间的映射链路。 当前页面把项目背景、前端职责和默认接口约定整理成统一说明，方便本地联调与后续部署。

Project

项目目标

通过 EEG 数据估计用户状态，再将状态映射为音乐生成参数， 最终生成符合情绪与偏好约束的旋律、和声与评估结果。

Frontend

前端职责

负责参数输入、字段校验、草稿保存、INI 导出，以及和后端完成健康检查、 配置提交、生成请求与结果展示。

Backend

后端职责

负责读取 EEG 文件、执行信号分析、生成 MIDI 与中间产物， 并在需要时串联评估流程，返回统一 JSON 结果。

Generation Flow

推荐处理流程

  • 导入 EEG CSV，并选择需要分析的时间窗口。
  • 设置拍号、音域中心、力度预设和旋律限制。
  • 决定是否启用和弦轨，并指定调性、情绪与和弦风格。
  • 保存草稿或导出 INI，然后把完整参数发送给生成服务。

API Contract

默认接口约定

  • GET /api/health 用于健康检查。
  • POST /api/preferences 接收 JSON 配置快照。
  • POST /api/pipeline/run 上传 EEG CSV，并在一次请求中执行生成与评估。
  • 所有响应保持 JSON，并包含任务状态、生成产物、评估结果和清晰的错误信息。
